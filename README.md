# 다산고등학교 기념일 홍보 활동 신청 화면

https://h33-1.github.io/dasan-anniversary/

국내·세계 기념일 홍보 활동 신청을 위한 5단계 화면입니다.

현재 공개 버전은 서버와 연결하지 않은 화면 미리보기입니다. 신청 내용은 저장되지 않으며 선착순 예약·기존 신청 조회·수정·취소 기능은 활성화되어 있지 않습니다.

학년·반·번호·이름 입력 → 개인·팀 선택 → 월별 기념일 선택 → 제작 유형 선택 → 신청 내용 확인.

배포: main 브랜치 / 루트. 공개 저장소에는 HTML과 화면 이미지 파일만 포함합니다.
학생 신청 데이터, Google 시트 ID, Apps Script 서버 코드 및 연결 주소는 포함하지 않습니다.
